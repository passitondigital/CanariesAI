# Canaries AI skills

Saved instructions Claude follows for repeatable jobs. To install one, open its `.skill` file in Claude and tap **Save skill**.

| Skill | What it does |
|---|---|
| `website-clarity-audit` | Free taster: a warm 2–3 page website check-up for a prospect, scoring clarity, AI search visibility, trust and time-saving ideas, with one next step. |
| `website-full-audit` | Paid audit: up to 20 pages, six scored areas, competitor and Google listings checks, paste-ready rewrites, business label code, a week-by-week action plan and a portal-ready `audit-data.json`. |
| `capture-unfinished-tasks` | At the end of a chat, saves unfinished work, decisions, next steps and blocked items to Sue's command centre. |

Each skill folder has its instructions (`SKILL.md`), any reference notes or scripts, and an `evals/` folder of test cases. After editing a skill, repackage it so the `.skill` file matches.
